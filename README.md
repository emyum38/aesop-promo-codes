## How to enter a promo code at Aesop checkout

The code box is easy to miss. It sits on the **cart summary page**, not at the payment step — look for the plus sign next to "Apply a promotional code," expand it, paste the code, and the discount or gift should show in your order total before you continue to payment.

The steps in full:

1. Add your items to the cart on aesop.com.
2. Open the cart summary page.
3. Click the plus sign next to "Apply a promotional code."
4. Paste the code (extra spaces pasted in will make it fail; watch for O/0 and I/1 mix-ups too).
5. Confirm the gift or discount appears in your order total before paying.

If nothing changes after step 5, the code didn't apply — don't assume it will show up later. Move to the troubleshooting section below.

## Aesop shipping costs and the free-shipping threshold

Shipping is the easiest guaranteed saving on any Aesop order, and the thresholds are published on Aesop's own help pages. On the US site, orders of $51 or more ship free via Ground; below that, Ground costs a flat $8. Given that a single hand wash sits well under the line, one extra item usually covers the gap and beats paying $8 on a small order.

The full US picture, per Aesop's official delivery page:

- **Ground:** free at $51+, otherwise $8, arriving in 3–6 working days
- **Expedited:** $15, 1–2 working days
- **Next Day Delivery:** $20, arrives the next working day

All orders take 1–4 days to process before they ship, orders placed after midday Friday roll to the next working day, and couriers don't deliver weekends or to PO Boxes. Two less-obvious restrictions: flammable items (which includes some fragrance and certain care products) can't travel by air, and Aesop currently can't ship to Alaska, Hawaii, or APO/FPO addresses at all. If you're in those states, the US site checkout is a dead end regardless of any code.

On the UK site, the threshold is free standard delivery over £50, with £5 standard shipping below that (3–5 working days) and £8 next-day delivery if you order before midday.

## When your Aesop promo code fails

Codes fail for predictable reasons. Before concluding the code is dead, run through this list:

- **It expired.** Code lifespans at Aesop average around 30 days, and the UK "15OCTOFF" code, for example, states an expiry of 2 November 2026. Check the source page for a current status.
- **Extra spaces.** A space pasted before or after the code makes checkout reject it. Retype it manually if pasting fails twice.
- **Threshold not met.** The $125, $145, and $150 gift codes are hard minimums, calculated before tax and shipping.
- **Excluded products.** Gift sets and limited editions are frequently excluded from code eligibility.
- **A second code already applied.** Only one code per order — remove the first before testing another.
- **Account-specific restrictions.** Some codes are email- or app-only; a code requiring a new-customer account fails if the same address has ordered before.
- **The code was never real.** Aggregators recycle expired codes for years. If a site claims 80% off sitewide, the odds it survives checkout are close to zero given Aesop's two-year record of $0 discounts.

Two technical fixes that solve the stubborn cases: open a fresh browser tab (an old cart session can block updated pricing) and switch from mobile to desktop, since mobile keyboards and autofill are a common source of invisible spaces.
